# Security

Please report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability** (private vulnerability reporting). Please do not open a public issue for security problems.

This is a multi-user app that stores people's answer history and uses JWT login. In scope: authentication or authorization bypass, ways to read another user's records, and secrets leaking into the repo. Before you deploy, read the "security checklist" section of the README.

這是一套多人使用、會儲存作答紀錄並以 JWT 登入的系統。發現認證／授權繞過、可讀取他人紀錄、或機密外洩的問題，請從本 repo 的 **Security** 分頁選 **Report a vulnerability** 私下通報，不要開公開 issue。
